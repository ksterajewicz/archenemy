# Contributing to archenemy

Thanks for helping. A few rules keep the project usable and legally clean.

## License of contributions

archenemy is licensed under **GPL-3.0-or-later** (see [LICENSE](LICENSE)).
By submitting a contribution (pull request, patch, issue attachment) you agree that it is
licensed under the same terms — **inbound = outbound**. Only submit work you wrote yourself
or have the right to submit under GPL-3.0-or-later.

Third-party files are welcome only with a compatible license. Keep their original notices and
add a row to [THIRD-PARTY.md](THIRD-PARTY.md) with the source URL, version and license.
Do not add logos, trademarks or copyrighted artwork (wallpapers, screenshots of films or games)
without written permission — wallpapers in this repository are generated by scripts in
`scripts/wallpapers/`.

## Before you open a pull request

- Run the whole test suite and keep it green: `LC_ALL=C.UTF-8 bash tests/run-all.sh`.
- Shell scripts start with `#!/usr/bin/env bash` and are committed with mode `100755`
  (`tests/repo-hygiene.sh` checks both).
- No machine-specific data in tracked files (monitor names, hostnames, user paths, secrets).
- Update `README.md` when you add or change files, keys or installer steps.
- Arch Linux is the reference platform; Fedora and NixOS support is experimental.
